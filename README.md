 ║    DESCRIPCIÓN       ║
 
 
 Este proyecto podría tener actualizaciones en un futuro 
 
 
 Ultron Panel es un proyecto desarrollado en Python que busca crear una experiencia de control personal inspirada en interfaces de inteligencia artificial y sistemas futuristas.
 
 El objetivo principal del proyecto es crear un panel ligero, personalizable y fácil de ampliar.
 
 El proyecto está diseñado para usuarios que quieren aprender, modificar y construir nuevas funciones sobre una base sencilla y organizada
 
 Si tú quieres modificar el código te recomiendo hacer una copia de seguridad antes de modificarlo
 
 
 ║ CARACTERÍSTICAS     
       PRINCIPALES       ║
 
 
 - Interfaz de terminal con diseño inspirado en sistemas avanzados de inteligencia artificial.
 - Panel con identidad visual propia.
 - Código abierto y modificable.
 - Estructura preparada para añadir nuevas funciones.
 - Personalización de colores, estilos y módulos.
 - Ejecución mediante Python 3.
 
 
 ║     REQUISITOS       ║
 
 
 Antes de ejecutar Ultron Panel necesitas:
 
 - Python 3 instalado.
 - Git instalado (opcional, recomendado para descargar actualizaciones).
 - Un sistema compatible:
   - Linux
   - Windows
   - Otros sistemas con soporte para Python
 
 Este proyecto está dirigido a usuarios de Linux principalmente 
 
 
 
 
 ║    INSTALACIÓN       ║
 
 
 Método 1: Clonar el repositorio
 
 Primero descarga el proyecto desde GitHub:
 
 git clone https://github.com/NATH-DEVcode/Ultron-Panel.git
 
 Después entra en la carpeta del proyecto:
 
 cd Ultron-Panel
 
 A continuación use este comando 
 
 source venv/bin/activate
 
 si no tiene instalado venv use este comando
 
 sudo apt update
 sudo apt install python3-venv
 
 
 
 ║      EJECUCIÓN       ║
 
 
 Para iniciar Ultron Panel utiliza:
 
 python3 main.py
 
 En Windows también puede funcionar con:
 
 python main.py
 
 
 En Windows puede no funcionar o no funcionar bien debido a que este proyecto este principalmente dirigido a usuarios de Linux ya que se usan rutas que Windows podría no tener o no tener los siste[...]
 
 
 
 Al iniciar correctamente aparecerá la interfaz principal del panel.
 
 
 ║    PRIMER USO        ║
 
 
 Cuando abras Ultron Panel:
 
 1. Espera a que cargue la interfaz.
 2. Revisa las opciones disponibles.
 3. Utiliza las funciones disponibles dentro del menú.
 
 Se recomienda tener conocimientos básicos de Python si deseas modificar el funcionamiento interno del proyecto.
 
 
 ║   PERSONALIZACIÓN      ║
 
 
 Ultron Panel está creado para poder adaptarse a diferentes necesidades.
 
 Puedes modificar:
 
 - Colores del tema.
 - Texto de la interfaz.
 - ASCII del inicio.
 - Nuevas funciones.
 - Nuevos módulos.
 - Comandos personalizados.
 
 Antes de realizar cambios importantes se recomienda crear una copia del proyecto.
 
 
 
 ║    RECOMENDACIÓN     ║
 
 
 Instalación de dependencias
 
 El proyecto pude incluir dependencias que no están en los archivos 
 
 Instala los paquetes necesarios con:
 
 pip install -r requirements.txt
 
 Si no existe ese archivo, puedes continuar con la ejecución.
